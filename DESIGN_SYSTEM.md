# Sistema visual EDDIP Premium

- Azul principal: `#0F59DF`
- Azul profundo: `#073B9D`
- Azul eléctrico: `#2F86FF`
- Navy: `#071F49`
- Fondo suave: `#F6F9FE`
- Tipografía: Poppins
- Bordes: 14–18px en cards, 24–30px en grandes composiciones
- Animaciones: flotación suave, hover vertical, sombras progresivas y transiciones de 200–250ms
- Home: alternancia de blanco y fondos azul degradado para mantener ritmo visual
